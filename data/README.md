# data/
- `reference_prices.csv` — one reference price, flagged NEEDS VERIFICATION (see its columns). Never used in calculations.
- `sample_data/synthetic_rule_labelled_demo.csv` — SYNTHETIC, generated by `python -m ml.train_model --synthetic-demo`; labels come from the app's own rules. Pipeline demo only.
- `pilot/labelled_batches_TEMPLATE.csv` — column template for REAL pilot data (one row per batch, `outcome`=1 if downgraded/rejected/lost at sale or inspection, else 0). Save real data as `pilot/labelled_batches.csv` and run `python -m ml.train_model --csv data/pilot/labelled_batches.csv`.
- No real labelled dataset linking NTFP storage conditions to outcomes was found (searches 28 Oct 2026); see docs/data_sources.md.
